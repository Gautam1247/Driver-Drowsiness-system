# AI-Based Real-Time Driver Monitoring and Safety Violation Detection

A real-time AI-based driver monitoring system using deep learning and computer vision.

## Planned Features

- Driver drowsiness detection
- Prolonged eye closure detection
- Yawning detection
- Mobile phone usage detection
- Seatbelt violation detection
- Temporal behavior analysis
- Driver safety decision engine
- Audio and visual alerts

## Architecture

YOLO + CNN + OpenCV + Temporal Analysis

## Technology Stack

- Python
- PyTorch
- YOLO
- OpenCV
- MobileNetV2
- NumPy
- scikit-learn

## Project Status

Currently developing the eye-state classification module.
